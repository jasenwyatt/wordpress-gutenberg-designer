# Service hero example

This example demonstrates the intended handoff shape:

- `wordpress-design.json` describes the design and block tree.
- `theme.json` contains reusable visual presets.
- `patterns/service-hero.php` contains editable Gutenberg markup.
- `preview/index.html` shows the visual projection.

The placeholder image is deliberately obvious. Production output should copy or reference supplied project assets instead of quietly borrowing a random photograph from the internet.
